# timetable-ab —— 原始数据

> **这是一份完整的原始实验数据。里面既有结论，也有把结论推翻的过程。**
> 数据没有清洗过：失败、返工、自相矛盾的记录都留着。

## 一眼看懂

```
1 份冻结规格（5 个 op：add / del / edit / move / swap）
  → 7 个语言各写一遍，每人一个隔离上下文的 agent
  → 36 条不变量判据（每条都证明过"会红"）
  → 再加 14 份后续规格：规模、扇出、展开期校验、内联、维护、交接、30 op 交叉
```

**7 个语言**：Common Lisp / JavaScript / Java / Rust / Julia / Python / C++

## 怎么复算（三条命令）

```bash
# 1) 体积（主口径：非空白非注释字符）
node metric.cjs runs/f-python/impl.py
node metric.cjs runs/f-cpp/impl.cpp

# 2) 判据（36 条不变量）
node check-scale.cjs --impl runs/scale-lisp/impl.lisp        # → 36 passed, 0 failed
node check-scale.cjs --impl runs/scale-js/impl.js            # → 36 passed, 0 failed

# 3) 变异测试（给判据本身打分）
node mutate.cjs --sample 30 --only 1,2,3 --impl runs/scale-lisp/impl.lisp
node gate.cjs                                                # → 低于地板分则 exit 1
```

跑环境：SBCL 走 `$env:SBCL`；C++ 走 `$env:CXX`；Python 走 `python`；Java 走 `javac`。

## 目录

```
tasks/      14 份冻结规格（跑之前就写死，不许中途改）
cases/      判据用到的固定输入
runs/       513 个产物文件：每个臂一份 impl + 报告 + 探针
check-scale.cjs    36 条不变量（含 --only 守卫、三语言分派）
mutate.cjs         变异测试器（按"新增失败"判定杀与否）
gate.cjs           门禁（读 mutation-floors.json，低于地板退出 1）
metric.cjs         三个口径：物理行 / 代码行 / 非空白非注释字符
repl.mjs           活体 REPL 驱动（供"允许 REPL"的臂使用）
```

**排除的**：编译产物（`*.exe` / `*.fasl` / `*.class`）、构建缓存、本机临时文件。不含任何个人数据。

## 七语言体积（5 op，非空白非注释字符）

| 语言 | 字符 | JSON 通道 |
|---|---|---|
| Python | **4750** | 标准库 |
| JavaScript | 5933 | 标准库 |
| Java | 6970 | 手写 |
| Julia | 7316 | 手写 267 行 |
| Common Lisp | 7506 | 手写 |
| Rust | 9390 | 手写 |
| **C++** | **11374** | **手写 242 行（占 49.6%）** |

> 主口径是**非空白非注释字符**。物理行数不能当主口径——同一份代码的物理行能差 **4.05 倍**，而字符只差 **7.6%**。行数量的是排版。

## 里面有什么"反直觉"的东西

1. **行数不是语言属性**：同一规格的两种实现，物理行差 4.05×，字符差 7.6%。
2. **宏在这一规模上输**：同样 15 个 op，CL 11460 字符 vs JS 5933。
3. **没有观测到正交叉点**：沿 op 数推，代数值在本轮为负。
4. **技能包没有可测效应**：6 run 的 A/B，两臂边界错误都是 0/3——因为执行者的错误率已贴地板（天花板效应）。
5. **"Lisp 笨重"失去区分度**：最笨重的是 C++（11374），而没人说 C++ 不该用。

## 两条后来补的对照（2026-10-25）

| 目录 | 是什么 | 结论 |
|---|---|---|
| `linter/` | 四种缺陷 × 三种入口（`node --check` / `eslint no-undef` / `sbcl compile-file`） | **差别是摩擦，不是能力**：JS 装一次 eslint 后与 CL 打平；语义类三语言都漏 |
| `runs/n5-cl-1..5`、`runs/n5-js-1..5` | 同一份缺陷复制十份，十个隔离 agent 各修一份 | **返工轮数方差为 0**（10/10 全 1 轮、同一行、零错假设）；归因时延 CL 中位 9s vs JS 8s，区间重叠 |

## 十九次"我以为我测过了"

数据里最贵的部分不是数字，是 `../docs/experiment-report.md` 里那份只追加的编年史——
记录了 **19 次**测量工具本身出错的过程，包括：

```
判据在"功能根本没实现"的代码上也能通过（至少 4 种不同机制）
种点替换没匹配上，却打印了"已加"
变异得分 100% 是假的，因为基线有 2 条红
主结局用"某种报错文本"定义，漏掉静默塌缩的那一半
```

**每一条都附了症状、怎么发现的、以及它变成的规则。** 共 15 条纪律，见 [`../PROTOCOL.md`](../PROTOCOL.md)。

## 诚实边界（未验证的，别当结论）

```
× 样本数：多数格子 n=1，只有 A/B 对照是 n=3
× 单一模型：全部由同一个模型家族完成，跨家族未测
× 规模：最大 30 op / 千行级，更大规模未测
× 未断网：联网状态下完成，检索行为未隔离

```
