# 曲率实验（curv）：加 20 个形状递增的 op，测每 op 增量

目的：检验"每加一个 op 越来越便宜"（复利）还是"恒定"（线性低斜率）。
基线：`runs/scale-lisp/impl.lisp`（467 行，已有 `defop` DSL + 15 个 op）。

## 硬规矩

1. **只允许加 op，不许改已通过的 15 个 op 的行为**；有回归即失败。
2. 每加一个 op，立刻记录**加入后的 `impl.lisp` 行数（LF 计数）**与**本步 diff 新增行数**。
3. 每加完一个，跑 `check-scale.cjs` 全表（19 条）必须仍全绿。
4. 不许为了"省行数"而压缩已有代码——本实验测的是增量。

## 20 个 op，分四层（每层 5 个）

一层：**纯横切**（只有 match + 常量）
- `mark1` … `mark5`：给命中课的 `note` 字段写 `"m1"`…`"m5"`。

二层：**组合两个已有一层 op**
- `pair1` … `pair5`：等价于依次执行 `markN` 与 `tag`（`tag:"pN"`）。
- 要求：**不复制两个 op 的实现**，用已有声明组合。

三层：**组合上一层**
- `triple1` … `triple5`：等价于 `pairN` 再加一次 `markN`（note 追加一个字符）。
- 同样不许复制实现。

四层：**参数化批处理**
- `bulk1` … `bulk5`：对命中的每门课，依次执行 `mark1..mark4` 中的前 K 个（K=1..5）。
- 允许在声明里写循环/列表，但不许把前面的 body 抄一遍。

## 每步要记的数

```        
<HH:mm:ss> | op=<名字> | 层=<1-4> | 加入后行数=<L> | 本步新增=<d> | 动了几处=<n>（列出位置） | checker=19/19
```

## 判读

- 若"本步新增"随 op 序号**下降** → 曲率存在（复利）。
- 若**恒定** → 线性低斜率。
- 若**上升** → 抽象在漏，越加越贵。

层与层之间允许出现台阶（组合层本来就更难），**判读只做同层内的趋势**。
