# t2b：宏的第三层——展开期校验能不能挡住"测试看不见的错误"

## 要证明的一件事（只有一件）

> 存在一种错误：**现有 19 条判据全绿，但代码是错的**。
> 宏能不能在**展开期**把它拦住？

已知的病历：本项目两次假绿（`tag-untag` 在 op 未实现时通过；curv 的 20 个新 op 零覆盖）。
这一轮就是给"宏能挡住这类错误"做一次可复现的证明。

## 基线

`runs/t2b-lisp/impl.lisp` = `scale-lisp` 原样（467 行，`defop` DSL，15 个 op，判据 19/19）。
**不要动 19 条判据，不要改 ops 的行为。**

## 要做三件事

### 1. 给 `defop` 加展开期校验，至少拦住五类

| # | 非法形态 | 要求 |
|---|---|---|
| a | **同名 op 注册两次** | 报错，点名重复的 op 名 |
| b | `:need` 里的字段不在该 op 允许的字段集合内 | 报错，点名字段 |
| c | 缺 `:text` | 报错，说明缺哪一项 |
| d | 执行体为空 | 同上 |
| e | op 名为空串 / 非字符串 | 报错 |

报错必须在**加载（展开）时**发生，不能等到运行时才报。
报错信息必须**点名**（op 名 / 字段名 / 缺的项），不许只说 "invalid defop"。

### 2. 提供两个探针宏（判据要注入它们）

```lisp
(probe-duplicate "add")
;; 展开成：与已有 op "add" 同名、且行为完全相同的第二份声明
;; 目的：制造一个"行为上等价、因此测试看不见"的重复

(probe-bad :unknown-field)   ; 展开成 :need 里有非法字段的声明
(probe-bad :no-text)         ; 展开成缺 :text 的声明
(probe-bad :empty-body)      ; 展开成执行体为空的声明
(probe-bad :empty-name)      ; 展开成 op 名为 "" 的声明
```

**注意**：`probe-duplicate` 展开出来的第二份声明，其行为必须和原 `add` **完全一致**——
这样"测试看不见"才是真的（判据会验证这一点）。

### 3. 支持关闭校验（用于对照）

读环境变量 `T2B_VALIDATE`：等于 `"0"` 时**跳过所有校验**（照旧注册，后定义覆盖先定义）。

这条不是可选项——它是对照组，用来证明"这个错误确实是测试看不见的"。

## 判据

```powershell
$env:SBCL='C:\Users\HUAWEI\Documents\deepseek-harness\default-workspace\tools\sbcl\PFiles\Steel Bank Common Lisp\sbcl.exe'
$env:SBCL_HOME=Split-Path $env:SBCL
node ..\..\check-t2b.cjs --dir .
```

它会跑 11 条，核心是三组：

- **C2**：原文件能加载，且 check-scale 19/19（不能为了校验把手功能弄坏）
- **C3a**：`T2B_VALIDATE=0` + 重复声明 → **加载成功**，且 check-scale **仍 19/19** ← 证明测试看不见
- **C3b**：默认（校验开）+ 重复声明 → **加载失败**，报错含 `add` 与重复字样 ← 证明宏挡得住

> **C3a 与 C3b 的对照才是这个实验的全部价值。** 只有 C3b 而没有 C3a，
> 就证明不了"这条错误是测试挡不住的"。
