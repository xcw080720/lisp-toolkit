# RELEASE NOTES — v1.7.5（2026-11-02，门禁）

> 这一版改的不是说明文字，是**门禁的射程**：让回归门禁知道 `check-v4` / `check-hygiene` / `check-static` 存在，并且能拦住冻结文件被改。
> **没有改动任何测量数字、判据内容或数据集。**

---

## 一、找到的缺口

`gate.cjs` 的注释写着四步，四步全部围绕 `scale.spec`（30 op、36 条判据、K1–K7）。

**它完全不知道 `check-v4.cjs`、`check-hygiene.cjs`、`check-static.cjs` 存在。**

于是下面三件事都不会被拦住：

| 做一件 | 门禁反应 |
|---|---|
| 删掉 `check-hygiene.cjs` 或 `check-static.cjs` | 照常绿 |
| 把 `check-v4.cjs` 里某条判据改成永远通过 | 照常绿 |
| 改 `tasks/v3-full.spec.md` 一个字节，让所有冻结记录失效 | 照常绿 |

`docs/DO-NOT-MODIFY.md` 立过规矩，「任何改文件的脚本必须带机器可查的禁改清单」——**但当时没有一行代码在执行它**。

---

## 二、加的第五步

三个判据文件的 sha256 落进新文件 `v3-baseline.json`；同时记录十格基线（8 格 78/84、2 格 84/84）。

十格地板只在 `--v3-baseline` 下跑：其中六格是 Common Lisp，单格 65–77 秒，全跑约 12 分钟。

## 三、加的第六步

三个冻结文件的 sha256 与 `frozen-files.json` 逐项比对。

`frozen-files.json` **不是手写**——`make-frozen-list.cjs` 从 `FREEZE-*.txt` 记录反推生成。这样清单和记录不可能各说各话。文件被修订过的，取当前哈希，旧哈希留注。
