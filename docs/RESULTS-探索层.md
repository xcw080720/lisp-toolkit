## 4. 本层仍可用的东西

1. **量级**：三组比值与可核层方向一致（可核层：语言 0.71–0.91×、方案 1.21–1.54×）。
2. **机制解释**：抽象省的是校验/分发/文案那层样板，S ≈ 168 字符/op（由 `results-evo.tsv` 三批数据反推，可由可核层复核量级）。
3. **失效形态**：增量与维护阶段的零返工，反证了"抽象只在第一次立结构时更易集中失效"。
