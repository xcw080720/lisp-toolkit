## 2. 门禁补洞（`gate.cjs` 119 → 196 行）

原来 `gate → mutate → 只跑 check-scale`，**删掉 `check-closure.cjs` 门禁照样 PASS**。现在检查四项：配置自洽（`impls` ↔ `floors` 双向差集）、判据集指纹、实现缺失即 FAIL、证据表存证。另有 `--closure-only` 秒级自检。

验收＝**篡改测试**：A 原样 exit 0；B 删判据文件、C 改证据表、D 换会红实现、E 改指纹、F 删 floor 键、G 挪走实现 → 各自 exit 1 且红在正确原因；H 恢复 exit 0。

## 3. 契约边界与超纲判据

- `check-v3.cjs` 装了两个契约：1–36 = 15 op（`v3.spec.md`），37–56 = 30-op 变体。对 15-op 实现后者**恒红**，`36/56` 不是质量指标。现在**无 `--upto` 拒绝执行**。
- 新增 `--exclude-out-of-spec`：`#31`（未知命令）、`#32`（空命令串）在规格里无依据。
- **CL first_pass：36 条口径 2/12，spec 合规口径 5/12**（差出的 3 格只挂 #31/#32）。
- `#36`（swap 误报 CONFLICT）因 `v3.spec.md` L71 已明文覆盖，**转正**，失败算真错。
