## 四、为什么不一并补齐

因为补「当时的 notes」和补「现在的理解」是两件事。把 12 份当时没写的东西按今天的口径写出来，等于伪造当时的记录。

**能做的是：把这些缺口列出来，让后面的人在引用某一版时知道「这一版只有线上 notes，包里没有文件」。**

补齐它们需要一个明确的口径：是照 Zenodo 里的原文照抄（那叫搬运），还是按当前理解重写（那叫回顾，必须标记为回顾）。这件事没定之前，先不动。
