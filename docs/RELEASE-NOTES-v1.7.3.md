## 二、改的数值错误：`0.825` → `0.829`

v1.7.0 及之后的文档里，内联语言比的下界写成 `[0.825, 1.116]`，共 **18 处**。

权威表 `v4-ratios.tsv`（seed=20261101）给的是 **0.8286**，即 **0.829**。

**而 `RELEASE-NOTES-v1.6.3.md` 里明写着「端点由 0.825 统一为 0.829」——v1.7.0 把它退了回去。**

| 用法 | 处理 |
|---|---|
| 结论性引用（`1.008× [0.825, 1.116]`） | **改 0.829** |
| 口径说明（「端点只在第三位小数变动，例如 0.825–0.829」） | **保留 0.825**，那里这个数就是重点 |

保留的三处：`v4-ratios.tsv` 表头、`RELEASE-NOTES-v1.6.3.md`、`README.md` 里解释种子依赖的那段。
